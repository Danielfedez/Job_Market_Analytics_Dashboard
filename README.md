

# 📊 Job Market Analytics Dashboard

## 📌 Sobre el Proyecto

Este proyecto nace como una iniciativa de aprendizaje práctico para dominar Power BI y explorar las capacidades de modelado de datos, diseño de dashboards corporativos y storytelling visual. 

El objetivo principal es documentar mis avances en el uso de la herramienta creando un panel analítico interactivo que procesa y visualiza un dataset real con miles de ofertas de empleo en el sector tecnológico a nivel global.

## 🗃️ Estructura del Dataset

La base de datos analizada contiene información detallada sobre 478.895 publicaciones de empleo del sector *Tech*. Las principales variables procesadas son:

* **Información del Puesto:** `job_title_short`, `job_title`, `company_name`
* **Ubicación y Modalidad:** `job_country`, `job_location`, `search_location`, `job_via`, `job_work_from_home`
* **Condiciones Laborales:** `job_schedule_type`, `job_no_degree_mention`, `job_health_insurance`
* **Compensación Económica:** `salary_rate`, `salary_year_avg`, `salary_hour_avg`
* **Habilidades y Stack:** `job_skills`, `job_type_skills`
* **Temporalidad:** `job_posted_date`


## 🎯 KPIs Desarrollados

A través de este dashboard interactivo se analizan aspectos clave del mercado laboral tecnológico:

1. **KPIs Generales:** Volumen total de ofertas y medianas salariales globales (anuales y por hora).
2. **Distribución Salarial por Perfil:** Comparativa entre los puestos más cotizados (*Machine Learning Engineer, Data Engineer, Data Scientist, Data Analyst*, etc.).
3. **Análisis de Stack Técnico:** Mapeo y ranking de las tecnologías y competencias más demandadas por los empleadores (*Python, SQL, AWS, Power BI, etc.*).
4. **Beneficios y Modalidades:** Proporción de ofertas con opción de teletrabajo (*Work From Home*), requisitos académicos e inclusión de seguro médico.
5. **Tendencias Temporales:** Evolución mensual y trimestral en la publicación de ofertas de empleo a lo largo del año.
